# BMHM 0.3.5 validation — 2026-08-25 17:30:15

## Binary identity

The stock ALDL `PROM ID` field reports `305` for the entire engine-running portion of this log. This confirms the new `$4000-$4001 = 03 05` signature convention works in the stock datastream and positively identifies BMHM 0.3.5.

## Warm-start / fast-idle behavior

This was not a true cold start; coolant was about 69.5 C at engine start. It nevertheless validates the 0.3.5 fast-idle ordering and spark-authority changes.

Before the first real throttle opening:

- desired RPM follows the fast-idle coolant table continuously rather than alternating with the warm ~887 RPM target;
- desired RPM steps from about 975 toward 900 as coolant rises;
- idle spark is enabled for essentially the whole startup-idle period;
- spark is normally about 25-28 deg rather than being stuck at the former 38.3 deg overspeed value;
- actual RPM tracks the commanded fast-idle target closely, typically within a few dozen RPM after the initial start transient.

The first real throttle opening occurs around 144.2 s log time / 137 s engine run time. The repurposed first-drive-away latch sets immediately and FAST IDLE is cancelled for the remainder of the run.

## Bosch state layer after drive-away

After the FAST-IDLE latch sets, closed TPS above the TRUE-IDLE exit window remains DECEL and does not re-enter idle control. Closed TPS below the TRUE-IDLE entry threshold returns to the centralized idle state. State behavior remains consistent with the 0.3.2/0.3.4 architecture.

## PE/load override fault discovered

BMHM 0.3.5 attempted to add an actual-load PE qualifier at `$8AE7` using `$01C9`, which HAC comments as `Kpa VACUUM`, with a `<= 15` threshold.

The log proves this implementation is wrong for a direct full-load threshold:

- all 354 PE-active samples occur in the low-MAP/high-vacuum region, overwhelmingly below 20 kPa MAP;
- PE is active in about 84.9% of samples below 20 kPa MAP;
- PE is never active at MAP >= 20 kPa due to the new load override;
- the actual high-load region, about 75-85 kPa MAP, remains 0% PE even though that was the region the override was intended to capture.

Observed high-load region (MAP >=75 kPa, RPM >=1200):

- 123 samples;
- PE active: 0%;
- commanded AFR: 14.1 throughout;
- KR max: 4.0 deg;
- KR >0 on 92/123 samples;
- mean INT about 133.1;
- mean BLM about 126.5.

Therefore BMHM 0.3.5 must not be treated as the final PE implementation.

### Source correction

The source around `$A466-$A496` shows two separate load quantities:

- `$01C9` is generated from the BARO-vs-MAP A/D difference and is a transformed `VACUUM` coordinate used by several stock tables. It is not safe to treat as a direct 0-100 kPa MAP byte for a simple comparator.
- `$01C0` is explicitly produced and labeled `GET CURRENT MAP VALUE` and is the appropriate source for a direct actual-load MAP threshold.

The next implementation should qualify FULL LOAD from `$01C0` using a high-MAP comparison (for example MAP >= ~79 kPa at the current ~94.5 kPa baro) or, preferably, a baro-normalized load quantity if the source walk identifies a clean existing coordinate suitable for that purpose.

The 0.3.5 routine also set `$003F.b5` to bypass PE delay on its new load qualification. The stock exit path clears this bit at `$8C35`, so the observed decel PE is not a permanent latch; it is the direct result of qualifying the wrong load coordinate.

## High-load spark result

The base-spark reductions made in 0.3.5 did help. In the broad 1800-3100 RPM / 75-90 kPa region, compared with the preceding 0.3.4 drive, mean KR fell from about 3.5 deg to about 1.9 deg and the fraction of samples with nonzero KR fell from about 99% to about 67%.

The comparison is not perfectly matched because operating points differed, and PE still failed to enter at high load. Therefore further spark reduction should not be decided until the PE/load-state bug is fixed and the same area is retested with the intended richer full-load AFR.

## Closed-loop / VE result

The small mid-load VE correction behaved as intended. In clean closed-loop 2400-3100 RPM / 50-70 kPa operation:

- previous BLM mean: about 129.68;

- current INT mean: about 128.36;
- current mean abs(INT-128): about 2.42 counts.

The dominant part-load controller remains well centered. DAMP1 does not need additional authority changes from this log.
