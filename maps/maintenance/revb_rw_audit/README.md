# Rev B read/write audit evidence

Read the [audit findings](../../../docs/investigations/REVB_READ_WRITE_AUDIT.md)
for interpretations, corrections, qualified observations and remaining work.

| File | Contents |
|---|---|
| `WRITE_SITES.csv` | All 1,120 rooted explicit write sites, exact bytes, widths, fixed operands, finite abstract footprints and named-row associations. Includes RMW; excludes implicit stack writes. |
| `WRITERS_WITHOUT_NAMED_ROWS.csv` | Current sites without global address rows: two stack-local writes and one descriptor-selected copy, each with a traced routine role. The historical 92-site list is preserved in ../revb_write_roles/SEED_SITES.csv. |
| `PREAUDIT_UNINDEXED_WRITERS.csv` | Historical 108 sites missing before this audit; linked to the prior write-evidence SHA in the update journal. |
| `QUALIFIED_REFRESH.csv` | Eight read/write pairs across two admitted RAM-refresh intervals, each word start/stride/count separately qualified. |
| `EVIDENCE.json` | Exact selected Rev B excerpts; not a full BIN. |
| `EXECUTION_WITNESSES.json` | Thirteen scoped cases: refresh, six discarded DFCO-load cases, ADC timeout publication, IAC-shadow producer/publication, three BARO construction/fallback cases and current simulator resource observations. |
| `REGISTER_UPDATES.json` | Both maintained workbook before/after identities, added rows, Current use edits and write-evidence identities. Original OEM role text and both OEM books preserved. |
| `SUMMARY.json` | Current coverage and association counts, exact image identity and scope. |

```sh
python tools/audit_revb_rw.py --check-recorded
python tools/audit_revb_rw.py --rom /path/to/revb.bin
python tools/audit_revb_rw.py --rom /path/to/revb.bin --record
```

Run from the repo root. Full-image mode requires exact Rev B SHA-256 and
regenerates the write-site inventory and current association checks. Recorded
mode checks decoded write operands, fixed associations, workbook/evidence
identities and selected CPU witnesses; it does not reproduce whole-image
reachability or abstract contexts. The historical gap CSV and workbook journal
are reviewed audit records, not regenerated by `--record`.

Controlled byte storage does not simulate physical chip selects, ADC completion,
read-clear behavior, EEPROM, pin response or aliases. The simulator observation
case reports the current implementation; it is not an assertion that those
boundaries are correct for F1 or the GM derivative. Finite, qualified and
runtime-selected footprints remain separate and may overlap.
